- 仅支持博简 App 扫码，必须在 App 内确认。二维码原样编码后端 qr_content；按官方 HTTPS 域名、路径、fragment 参数、随机 ID 与凭据长度验证，浏览器私有凭据不进入二维码或客户端 JSON。
