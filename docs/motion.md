# 当前单屏页面

本轮按用户要求移除建筑图片并重新设计。首页改为纯排版的中文品牌页：大字号“博简”、简短文案、细分隔线与底部淡蓝渐变。页面保持单屏，下载与登录/账号位于右上角。下载未开放时展示真实状态；菜单支持键盘、Esc、外部点击关闭和互斥展开。

首页文案服务端渲染，不需要 JavaScript。背景仅使用 CSS，不加载照片、生成图片、外部字体或 WebGL。登录页在所有尺寸居中，保留二维码空态提示、同意后自动生成、到期换码和登录返回流程。原建筑图片不再被页面引用，也没有预加载请求；历史素材说明保存在 docs/assets.md。

菜单使用 160ms 透明度/位移入场，按钮有悬停和按压反馈。减少动态偏好下禁用动画和过渡。无自动轮播、持续动画或视差。旧 Motion 和粒子文件未挂载。

验证命令：`pnpm build`、`pnpm test:motion`、`pnpm test:auth`。视觉测试检查旧图片没有被请求、品牌排版不被裁切、不同尺寸单屏布局、菜单和页面往返，以及无 JavaScript 链接。截图为 artifacts/type-home-*.png 与 artifacts/type-login-*.png。
