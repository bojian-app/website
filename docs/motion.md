# 当前首页布局与交互

首页使用参考设计同款 Moraine Lake 照片，固定铺满视口；中央只保留一句主标题。顶部导航与页脚透明叠加，取消侧栏、功能介绍、底部卡片和正文操作按钮。公共导航继续与控制台共用组件和尺寸，首页使用适合照片的浅色文字，控制台保留白底。

首页内容服务端渲染，没有轮播、客户端状态、持续动画或 WebGL。Next.js Image 预加载并按屏幕优化照片，深色遮罩由 CSS 实现。手机竖向裁切，页面使用动态视口高度。素材来源见 docs/assets.md。

下载与登录只在顶部出现一次；下载展示“暂未上线”通知，3 秒自动消失，重复点击重新计时，支持键盘与 Esc。减少动态偏好下禁用动画和过渡。无 JavaScript 时仍可访问登录和法律文件。

验证命令：`pnpm build`、`pnpm test:motion`、`pnpm test:auth`。5 项页面测试覆盖图片加载、全视口背景、单一操作入口、多尺寸布局、通知、页面往返及无 JavaScript 链接；13 项认证与控制台测试验证业务流程。Docker 成品镜像及线上验证使用 deploy/smoke.mjs。
