# 产品首页的动效与交互

首屏入口定位到功能导览。访客可以用 `#screens` 中的按钮查看不同的完整手机界面和对应介绍。当前界面由 `aria-pressed` 标识，支持鼠标、触屏、Enter 和空格键选择。

`#features` 按场景组织简历和求职功能，使用标签和关联的内容面板。访客可以用左右方向键切换分组。每组的入口与能力说明也在完整功能目录中直接展示，整页截图和关闭 JavaScript 后都能阅读。求职社区展示贴文、批注和消息的示例。常见问题使用原生 `details` 和 `summary` 展开。

系统开启减少动态效果时仍可浏览产品截图、切换分组与展开问答。关闭 JavaScript 后，首页正文、默认截图、问答和法律页仍可阅读。

页头的下载按钮说明官网暂未开放下载。提示显示 3 秒，重复触发会重新计时，Esc 可以关闭。

运行 `pnpm build` 和 `pnpm test:motion` 验证截图加载与切换、键盘操作、问答、下载提示和无 JavaScript 浏览。布局回归覆盖 320、390、400、768、1024 和 1440 像素宽度。发布检查使用 `deploy/smoke.mjs`。
